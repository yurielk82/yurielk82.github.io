EV 모터 시험 프로파일 변환기

자동차 분야 연구기관 모터 시험실의 운전 프로파일 입력을 자동화한 외부 프로젝트입니다. 연구원들에게 시험기와 자료 구조를 설명 듣고, 한 줄씩 손으로 넣던 프로파일을 CSV에서 시험기용 XML로 바꾸는 변환기를 만들었습니다. 이어서 시험마다 손으로 지정하던 명령 열과 기록 설정을 자료에서 읽어 오도록 바꿨습니다. CSV만 올리면 XML이 나오고, 맞지 않는 자료는 변환을 거부하고 이유를 알립니다. 시험은 밤새 또는 주말 내내 돌기 때문에, 사람이 없는 시간에 난 오류로 그 시간을 통째로 버리지 않도록 감시·경보를 더했습니다.

주요 결과

  • 한 줄씩 손으로 넣던 운전 프로파일 입력을 변환기로 대체연구원들에게 시험기와 자료 구조를 설명 듣고 제작
  • 시험마다 손으로 하던 열 지정을 자동 매칭으로 대체연구원마다 다른 열 이름을 동의어 사전과 값의 범위·부호 분포로 알아보고 속도·토크·모터 분배각 명령 열을 자동 선택
  • CSV만 올리면 변환기준 XML을 서버에 내장하고 여러 파일을 한 번에 변환, 기록 설정과 측정 채널 78개도 변환 때 함께 적용
  • 문제가 있으면 변환을 거부하고 화면에 이유 표시매칭 점수 0.9 미만, 맞는 열이 없는 경우, 변환 뒤 재대조에서 값이 다른 경우
  • 밤샘·주말 무인 시험의 오류를 바로 알리는 감시·경보전류·전압·속도·온도 기준 초과와 장비 무응답을 감지해 메일로 알리고, 시험실 밖에서도 웹 화면으로 상태를 조회하며, 비상 단계에서는 수집을 자동 중단
  • 받은 시험 자료 8개를 먼저 분석해 6개가 기본 설정보다 짧아 변환이 멈추는 것을 확인자료 길이만큼만 바꾸고 나머지 step은 원본 값을 유지하도록 수정
  • 시험기가 다시 쓴 XML을 거부하는 제약 유지새로 더한 기능도 모두 원본 XML 글은 그대로 두고 값만 치환

문제와 시작

시험기 소프트웨어는 엑셀 자료를 읽지 못해, 0.1초 간격 8천~1만 step의 운전 프로파일을 한 줄씩 손으로 넣어야 했습니다. 연구원들에게 시험기와 프로파일 구조를 설명 듣고 CSV를 시험기용 XML로 바꾸는 변환기를 만들었습니다. 연구원들도 코드를 다뤄 요구와 제약을 코드 수준에서 주고받았습니다. 첫 판은 시험마다 어느 열이 속도·토크·추가 명령인지 직접 지정해야 했고, 연구원마다 열 이름이 달랐습니다.

직접 한 일

  1. 1. 연구원 요청과 자료 분석

    연구원들의 요청은 열 이름이 사람마다 다르니 CSV 첫 줄과 맞춰 본 뒤 변환해 달라는 것이었습니다. 받은 시험 자료 8개의 길이·간격·값 범위부터 확인했고, 6개가 기본 설정(10,000 step)보다 짧아 변환이 멈춘다는 것을 찾아 자료 길이만큼만 바꾸도록 고쳤습니다.

  2. 2. 자료에서 설정 읽기

    열 이름은 영어·한글 동의어 사전으로 알아보고, 이름이 뜻 없는 기호여도 값의 범위와 부호 분포로 알아봅니다. 속도·토크·모터 분배각 명령 열을 자동으로 고르고 열마다 점수를 보여 줍니다.

  3. 3. CSV만 올리면 변환

    기준 XML을 서버에 내장해 사용자는 CSV만 올립니다. 여러 파일을 한 번에 바꿔 묶음으로 받습니다. 저장 간격·최대 기록 시간·샘플링 주파수 같은 기록 설정과 측정 채널 78개도 변환 때 함께 바꿀 수 있습니다.

  4. 4. 문제가 있으면 멈추고 알림

    매칭 점수가 0.9보다 낮거나 맞는 열이 없으면 변환을 거부합니다. 변환 뒤에는 출력 파일을 다시 읽어 모든 명령 값을 대조하고, 하나라도 다르면 결과를 내지 않습니다. 실패한 파일과 이유는 화면에 표시합니다.

  5. 5. 배포와 인계

    웹 화면과, Python이 없는 시험실 PC에서 실행하는 단일 실행 파일을 같은 변환 코드로 만들었습니다. 사용법과 변환 규칙은 안내서 세 쪽으로 정리했고, 변환기가 하지 않는 일(단위 변환, 장비 허용 범위 검사, 시간 간격 재조정)도 적었습니다. 시험기가 다시 쓴 XML을 거부하기 때문에 새 기능도 모두 원본 글은 그대로 두고 값만 바꿉니다.

  6. 6. 무인 시간의 감시·경보

    시험은 한두 시간이 아니라 밤새 또는 주말 내내 돕니다. 저녁에 오류가 나면 하루가, 주말에 나면 주말이 통째로 버려졌습니다. 그래서 시험 장비와 연동해, 시험이 도는 동안 수집한 값을 전류·전압·속도·온도 기준과 비교해, 기준의 80%에 닿으면 경고, 기준을 넘으면 위험, 비상 단계에서는 수집을 자동으로 멈추게 했습니다. 일정 시간 자료가 들어오지 않으면 장비 연결이 끊긴 것으로 보고 따로 경보를 냅니다. 경보는 메일로 가고, 시험실 밖에서도 웹 화면에서 시험 상태를 조회합니다. 시험이 끝나면 단계별 경보 횟수와 고장 이벤트를 요약으로 남깁니다.
