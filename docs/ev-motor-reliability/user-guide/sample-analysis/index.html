실측 데이터 판정 기준

이 쪽은 실차 시험 엑셀을 판정할 때 쓰는 계산과 기준값을 정리한 참고 자료입니다. 웹의 실측 데이터 화면과 명령줄 analyze_sample.py가 같은 코드(analysis/domain/)를 씁니다. 입력 파일 형식은 실측 데이터 올리기에 있습니다.

판정은 네 가지입니다.

판정쓰는 열결과
온도 프로파일모터·IGBT·히트싱크 온도, 시간채널별 통계
토크-속도 분포차량 속도, 모터 토크운전 영역 비율, 출력
열적 한계세 온도 채널SAFE, WARNING, CRITICAL
신뢰성 평가세 온도 채널PASS, MARGINAL, FAIL

온도 프로파일

채널마다 평균, 표준편차, 최소, 최대, P95, P99를 냅니다. 계산에 쓰는 기본값은 다음과 같습니다.

항목기본값
피크 탐지 돌출도3°C 이상
온도 상승률 이동 평균 창60초(1초 간격 가정), 단위 °C/min
구간 통계 길이600초

토크-속도 분포

매 샘플을 차량 속도와 모터 토크로 네 영역에 나눕니다.

영역조건
역행(구동)속도 1 kph 초과, 토크 1 Nm 초과
회생속도 1 kph 초과, 토크 -1 Nm 미만
관성속도 1 kph 초과, 토크 절댓값 1 Nm 이하
정지속도 1 kph 이하

듀티 사이클은 정지, 저속(30 kph 미만), 중속(30~60 kph), 고속(60 kph 이상) 비율입니다.

출력은 P = T × ω로 구합니다. 모터 각속도 ω는 차량 속도를 타이어 반경으로 나누고 기어비를 곱해 추정합니다. 기본 기어비는 10.0, 타이어 반경은 0.32 m입니다.

참고: 기어비와 타이어 반경은 실제 차량 제원이 아니라 기본값입니다. 출력 값은 추정치로만 읽습니다.

열적 한계

채널별 최대 온도를 설계 한계와 비교합니다.

채널한계
모터85°C
IGBT150°C
히트싱크80°C

마진은 한계 - 최대 온도(°C)와 그 값을 한계로 나눈 비율(%)입니다. 판정은 다음 순서로 정합니다.

  1. 한 채널이라도 한계를 넘으면 CRITICAL입니다.
  2. 한 채널이라도 마진이 20% 미만이면 WARNING입니다.
  3. 나머지는 SAFE입니다.

특정 온도 이상에 머문 시간도 함께 셉니다. 기준 온도는 모터·히트싱크가 40, 50, 60, 70, 80°C, IGBT가 40, 60, 80, 100, 120°C입니다.

신뢰성 평가

온도가 오르내린 횟수와 폭으로 열피로 손상을 추정합니다. 모터, IGBT, 히트싱크 세 채널을 따로 평가하고, 손상이 가장 큰 채널이 전체 판정을 정합니다.

  1. 온도를 30초 이동 평균으로 다듬습니다.
  2. 봉우리와 골을 찾아 간이 rainflow 방식으로 열 사이클을 셉니다. 폭(ΔT)이 2°C 미만인 사이클은 버립니다.
  3. 사이클을 ΔT 구간 0 ~ 5, 5 ~ 10, 10 ~ 20, 20°C 이상으로 나눠 셉니다.
  4. Coffin-Manson 식 Nf = C × ΔT^(-n)으로 사이클별 수명 횟수를 구합니다. 기본값은 n = 2.5, C = 100000(IGBT 솔더 접합 기준)입니다. 화면의 Nf 칸은 평균 ΔT로 구한 값입니다.
  5. Miner 법칙으로 누적 손상 D = Σ(1/Nf)를 더합니다. 잔여 수명은 (1 - D) × 100%입니다.

판정 기준은 다음과 같습니다.

판정누적 손상 D
PASSD < 0.3
MARGINAL0.3 ≤ D < 0.7
FAILD ≥ 0.7

주의: Coffin-Manson 계수는 일반 기준값입니다. 시험 부품의 실제 수명 데이터로 맞춘 값이 아니므로 판정은 시험 간 비교용으로 씁니다.
