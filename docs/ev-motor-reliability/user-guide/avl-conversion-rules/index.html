AVL 변환 규칙

이 쪽은 AVL 변환기가 CSV 열을 고르고 XML 값을 바꾸는 규칙을 정리한 참고 자료입니다. 웹 화면과 PC 프로그램이 같은 규칙을 씁니다.

바꾸는 것과 두는 것

변환기는 XML 문서의 구조를 새로 만들지 않습니다. 원본 XML 글 안에서 정해진 속성 값만 바꿉니다.

대상처리
step별 속도·토크·추가 명령 값(DEMAND_VALUE)CSV 값으로 바꿈
기록 설정(저장 간격, 최대 기록 시간, 저장 이름, 샘플링 주파수)값을 넣은 항목만 바꿈
측정 채널 설정채널 CSV를 넣었을 때만 바꿈
step 수, 채널 수, 그 밖의 줄그대로 둠

AVL PO15 Importer는 XML을 다른 도구로 다시 쓰면 namespace 위치가 바뀌어 “Not a valid PUMA Open XML file”로 거부합니다. 그래서 변환기는 XML을 파싱해서 다시 쓰지 않고 원본 글을 그대로 둔 채 값만 바꿉니다.

CSV 행과 step

CSV의 n번째 데이터 행이 XML의 n번째 step이 됩니다.

  • 시간 열 값으로 간격을 다시 맞추지 않습니다. CSV 행 간격을 템플릿 step 간격(내장 템플릿은 0.1초)과 맞춰 둡니다.
  • 단위를 바꾸지 않습니다. CSV 값이 그대로 명령 값이 됩니다.
  • 값이 장비 허용 범위 안인지는 검사하지 않습니다.

Target Steps

Target Steps는 바꿀 step 수의 상한입니다.

경우결과
CSV 행 수가 상한보다 적음CSV 행 수만큼만 바꿉니다. 나머지 step은 원본 값을 유지합니다.
CSV 행 수가 상한보다 많음앞에서부터 상한만큼만 씁니다.
XML step 수가 상한보다 적음변환을 멈춥니다. step이 더 많은 기준 XML이 필요합니다.

실제 운전 길이를 CSV보다 짧게 끝내려면 AVL 쪽에서 Cycle_demand 변수나 Max Recording Time 기록 설정으로 조절합니다.

자동 매칭

자동 매칭은 속도 명령(N_dem_E), 토크 명령(T_dem_E), 추가 명령(Alpha_d_P1) 세 변수마다 가장 맞는 CSV 열을 고릅니다. 열 이름과 열 값을 함께 봅니다.

열 이름

열 이름은 다음 동의어 사전과 비교합니다. 대소문자와 기호는 정리한 뒤 비교합니다.

XML 변수알아보는 열 이름
N_dem_Espeed, speed_cmd, rpm, n_cmd, 회전수, 속도, 회전수명령, 속도명령 외
T_dem_Etorque, torque_cmd, nm, t_cmd, 토크, 토크명령 외
Alpha_d_P1alpha, alpha_d, p1_angle, p1각도, 분배각, 추가명령 외

이름 점수는 완전히 같으면 1.00, 정리 후 같으면 0.95, 일부가 겹치면 0.6 ~ 0.8, 낱말이 겹치면 0.4 ~ 0.6입니다.

열 값

열 이름이 x1, col_a처럼 뜻이 없어도 값의 모양으로 변수를 알아봅니다.

변수값의 모양
시간간격이 일정하고 계속 늘어나며 음수가 없음
속도절댓값이 크고 음수가 거의 없음
토크회생 구간 때문에 음수가 섞여 있고 추가 명령보다 절댓값이 큼
추가 명령절댓값이 작고 음수가 있을 수 있음

이름과 값이 모두 맞으면 점수가 1.0에 가깝습니다. 둘 중 하나만 맞으면 0.7입니다.

점수와 거부

화면과 프로그램은 점수를 세 단계로 보여 줍니다.

점수웹 화면PC 프로그램
0.9 이상초록[OK]
0.6 이상노랑[MED]
0.6 미만빨강[LOW]

min-match-score보다 낮은 변수가 하나라도 있으면 변환을 거부합니다. 0.9로 두면 이름이 완전히 같거나 정리 후 같은 매칭만 통과합니다.

자동 매칭을 끄면 2번째 열을 속도, 3번째 열을 토크, 4번째 열을 추가 명령으로 씁니다. PC 프로그램에서는 열 번호(1부터)나 열 이름을 직접 넣을 수 있습니다.

검증

변환이 끝나면 저장한 XML을 다시 읽습니다. step 수와 모든 명령 값이 의도한 값과 같은지 대조하고, 하나라도 다르면 “Round-trip 검증 실패”로 결과를 내지 않습니다.

채널 CSV

측정 채널 설정을 고칠 때는 채널 목록을 CSV로 내보내 엑셀에서 고친 뒤 다시 넣습니다. 웹 화면은 내보내기만 하고, 고친 채널 CSV 반영은 PC 프로그램의 --channel-csv로 합니다.

열뜻
index_1base1부터 세는 채널 번호(필수)
quantity_ref측정 변수 이름
frequency채널 샘플링 주파수(Hz)
interpolation보간 방식
y_min, y_max표시 범위

빈 칸은 원래 값을 유지합니다. 행을 더하거나 지워도 채널 수는 바뀌지 않습니다.
