신뢰성 분석과 보고서 만들기

고장 시간으로 Weibull 수명을 추정하고, 고장 유형으로 FMEA 표를 만든 뒤, 결과를 HTML 보고서로 내려받습니다. 시뮬레이션 값과 실측 값의 차이도 같은 화면에서 비교합니다.

시작 전에 필요한 것

분석에는 다음이 필요합니다.

  • 승인된 대시보드 계정과 연결됨 상태의 Python API
  • Weibull 분석용 고장 시간 2개 이상(0보다 큰 값, 단위는 시간)
  • FMEA용 고장 유형과 발생 횟수

분석 화면은 입력한 값만 계산합니다. 실측 데이터에 올린 엑셀을 불러오지는 않습니다.

Weibull 수명 추정하기

  1. 왼쪽 메뉴에서 분석을 누르고 Weibull 수명 탭을 엽니다.
  2. 고장 시간 데이터 (시간) 칸에 고장 시간을 줄바꿈이나 쉼표로 나눠 넣습니다.
  3. Weibull 분석 실행을 누릅니다.
  4. Weibull 파라미터와 신뢰도 곡선이 나오면 끝입니다.

결과 항목은 다음과 같습니다.

항목뜻
Beta (형상)고장 양상. 1보다 작으면 초기 고장, 1 근처면 우발 고장, 1보다 크면 마모 고장
Eta (척도)전체의 63.2%가 고장 나는 시간
B10 수명, B50 수명10%, 50%가 고장 나는 시간
MTTF평균 고장 시간 η × Γ(1 + 1/β)
R²직선 맞춤 정도. 1에 가까울수록 Weibull 분포에 잘 맞음

모수는 중앙 순위 F = (i - 0.3) / (n + 0.4)로 Weibull 확률지 좌표를 만든 뒤 최소제곱 직선을 맞춰 구합니다(analysis/domain/weibull.py). 최대우도 추정과 신뢰 구간은 계산하지 않습니다.

FMEA 표 만들기

  1. FMEA 탭을 엽니다.
  2. 컴포넌트 이름을 넣습니다.
  3. 고장 이벤트 표의 고장 유형에 아래 여섯 값 중 하나를 넣고, 발생도 (1-10) 칸에 관찰한 발생 횟수를 넣습니다. 줄은 행 추가 아이콘으로 더합니다.
  4. FMEA 분석 실행을 누릅니다.
  5. 리스크 요약(총 항목, 최대 RPN, 평균 RPN)과 FMEA 상세 결과 표가 나오면 끝입니다.

주의: 고장 유형은 아래 여섯 값만 알아봅니다. 표에 처음 들어 있는 bearing_wear, winding_short, demagnetization은 알아보지 못해 결과에서 빠집니다. 첫 줄부터 아래 값으로 바꿔 넣습니다.

고장 유형고장 모드심각도 S검출도 D
overcurrent과전류83
overvoltage과전압93
overtemperature과열74
vibration이상 진동65
encoder_error엔코더 오류92
comm_timeout통신 시간 초과42

원인, 영향, 조치 문구와 S, D는 고장 유형별로 정해진 값을 씁니다. 입력한 발생 횟수는 발생도 O 등급으로 바뀝니다. 0회는 1, 1 ~ 2회는 2 ~ 3, 3 ~ 5회는 4 ~ 5, 6 ~ 10회는 6 ~ 7, 11 ~ 50회는 8, 51 ~ 100회는 9, 100회 초과는 10입니다.

위험도는 RPN = S × O × D로 나눕니다.

RPN위험도
1~49LOW
50~99MEDIUM
100~199HIGH
200 이상CRITICAL

시뮬레이션과 실측 비교하기

  1. 시뮬 vs 실측 탭을 엽니다.
  2. 정상상태 비교에 속도(rpm), 전류(A), 토크(Nm)의 시뮬레이션 값과 실측 값을 넣고 정상상태 비교 실행을 누릅니다.
  3. 과도응답 비교에 상승 시간, 정착 시간, 오버슈트를 넣고 과도응답 비교 실행을 누릅니다.

결과 표에 항목별 시뮬레이션, 실측, 오차, 오차율 (%) 값이 나옵니다.

보고서 받기

  1. Weibull, FMEA, 비교 중 하나 이상을 실행합니다.
  2. 화면 아래 보고서에서 보고서 생성을 누릅니다.
  3. “보고서 생성 완료” 알림이 뜨면 다운로드를 누릅니다.

report_연월일_시분초.html 파일을 받습니다. 그때까지 실행한 Weibull, FMEA, 비교 결과가 한 문서에 들어 있습니다.

잘 안 될 때

  • “Weibull 분석 실패”가 뜨면 고장 시간이 2개 이상이고 모두 0보다 큰지 봅니다.
  • FMEA 결과가 비어 있으면 고장 유형 값이 위 여섯 값과 같은지 봅니다.
  • 그 밖의 증상은 문제 해결을 봅니다.
