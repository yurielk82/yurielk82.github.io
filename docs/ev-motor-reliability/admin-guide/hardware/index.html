펌웨어와 시험 장비

이 쪽은 시험 장비 구성, 펌웨어 소스, 장비와 PC 사이 통신 형식을 정리한 참고 자료입니다. 운영 서버에는 장비가 연결되어 있지 않습니다. 이 내용은 장비가 있는 PC에서 API를 띄울 때 씁니다.

장비 구성

개발과 검증은 SMC300 모터제어 패키지로 했습니다.

구성품내용
SMC300 개발보드, F2838x DOCK 보드제어 보드
TMS320F2838x 모듈TI C2000 계열 모터 제어 DSP
3상 PMSM26W, 인크리멘탈 엔코더
3상 BLDC 모터20W, 홀 센서
SDS200i절연 JTAG 에뮬레이터(XDS200-ISO), 펌웨어 쓰기·디버깅

PC는 JTAG로 펌웨어를 쓰고, UART(SCI)로 측정값을 받습니다. 보드 전원은 24V DC입니다.

펌웨어 소스

firmware/ 아래 C 소스가 있습니다.

파일내용
src/main.c상태 머신(INIT, IDLE, RUN, FAULT, STOP) 주 루프. 제어 루프는 10 kHz PWM 인터럽트에서 실행
src/motor_control.cPID와 하드웨어 드라이버를 묶는 제어 상위 로직
src/safety.c과전류 같은 보호 로직
src/algorithm/pid.c, src/algorithm/foc.cPID, FOC 알고리즘
src/hal/hal_adc.c, hal_pwm.c, hal_qep.c, hal_uart.cADC, PWM, 엔코더, UART 드라이버
include/board_config.h, include/types.h보드 설정, 공통 타입

주의: firmware/ccs_project/에는 빈 자리 표시 파일만 있습니다. Code Composer Studio 프로젝트 파일이 없으므로 make build, make flash, firmware/build.sh는 저장소만으로는 끝까지 돌지 않습니다. 빌드하려면 CCS에서 C2000Ware를 포함한 프로젝트를 만들고 이 소스를 넣습니다.

UART 측정 형식

펌웨어는 115200 baud로 한 줄에 한 샘플씩 쉼표로 나눈 글자를 보냅니다.

timestamp_ms,speed_rpm,current_a,voltage_v,position_deg
값단위
timestamp_msms
speed_rpmrpm
current_aA
voltage_vV
position_deg도

PC 쪽 수신은 automation/infrastructure/serial_comm.py가 맡습니다. 줄 끝은 CR LF입니다.

장비 설정 파일

장비가 있는 PC에서는 automation/config.yaml.example을 automation/config.yaml로 복사해 고칩니다. automation/config.yaml은 git에 올리지 않습니다.

묶음항목
serialport, baudrate, timeout_sec
jtaguniflash_path, target_config
safetymax_current_a, max_temperature_degc, max_vibration_g, emergency_stop_enabled
logginginterval_ms, output_dir, channels

자동화 코드의 현재 범위

automation/ 아래 코드는 라이브러리로만 쓸 수 있습니다.

  • automation/infrastructure/jtag_flash.py는 UniFlash 명령줄 도구 dslite.sh를 불러 펌웨어를 씁니다.
  • automation/data_collector.py는 UART 측정값을 motor_data_연월일_시분초.csv 파일로 모으고, automation/realtime_monitor.py는 안전 한계를 넘으면 정지를 요청합니다.
  • automation/pipeline.py의 TestPipeline은 폴더 준비, 감시 시작, 수집, 집계를 차례로 부릅니다.

이 모듈들은 명령줄 진입점이 없습니다. 웹의 모니터 화면 하드웨어 모드와 API /hardware 경로가 수집 시작·중지와 긴급 정지를 부르는 실제 입구입니다.

시뮬레이션 모델

simulation/ 아래에 DC 모터, PMSM(d-q 좌표), 인버터 모델과 PID, FOC 제어기가 있습니다. python -m simulation.runner는 DC 속도·위치, PMSM FOC 속도·토크 네 가지 예시를 돌려 지표를 출력합니다. 명령줄 인자는 받지 않고 파일도 만들지 않습니다.
