문제 해결

증상별 원인과 조치를 정리합니다. 먼저 avl.dvsharp.com/api/v1/health 응답에서 python, database, git이 connected인지 봅니다.

AVL 변환

증상원인조치
화면을 열자마자 “세션 생성 실패”API가 변환 세션을 만들지 못함API를 다시 시작하고 화면을 새로 고침
변환할 때 “template_xml 과 csv_profile 둘 다 업로드해야 합니다.”서버에 내장 기준 XML 파일이 없음(git에 올리지 않는 파일)서버에 기준 XML을 두거나, 사용자가 고급: 다른 base XML 사용 (선택 사항) 항목에서 올림
변환이 매칭 점수 때문에 거부됨한 변수의 자동 매칭 점수가 min-match-score보다 낮음AUTO-MATCH 결과에서 낮은 변수를 확인. CSV 열 이름을 동의어 사전 표기로 고치거나 점수 기준을 낮춤
”Round-trip 검증 실패”저장한 XML을 다시 읽은 값이 의도한 값과 다름기준 XML이 손상되었거나 변수 이름이 맞지 않는지 확인. 다른 기준 XML로 다시 변환
”XML step 수가 목표 step 수보다 부족합니다.”기준 XML의 step 수가 Target Steps보다 적음Target Steps를 줄이거나 step이 더 많은 기준 XML을 씀
413 응답업로드 파일이 50MB를 넘음파일을 나눠 변환
1시간 뒤 다운로드가 안 됨세션 폴더가 1시간 뒤 지워짐새 변환 시작으로 다시 변환
”CSV 파일 필요”CSV를 고르지 않고 진행함운전 프로파일 CSV 선택 (다중 가능) 버튼으로 파일을 고름

실측 데이터

증상원인조치
”업로드 실패”에 필수 컬럼 누락엑셀 3행 열 이름이 time, Veh_Velocity, Mot Temp, Igbt Temp, Heatsink Temp, Mot Tq와 다름열 이름을 글자 그대로 맞춤
차종·프로토콜이 unknown파일 이름이 SAMPLE_차종_EV_프로토콜_조건_모드.xlsx 형식이 아님파일 이름을 바꿔 다시 올림
.csv, .xls가 올라가지 않음.xlsx만 받음엑셀에서 .xlsx로 저장
대시보드 실측 데이터 카드 숫자가 목록과 다름카드와 목록이 서로 다른 경로로 집계함실측 데이터 화면의 업로드 목록을 기준으로 봄

분석·시뮬레이션

증상원인조치
FMEA 결과가 비어 있음고장 유형이 알아보는 여섯 값(overcurrent, overvoltage, overtemperature, vibration, encoder_error, comm_timeout)이 아님여섯 값 중 하나로 바꿈
”Weibull 분석 실패”고장 시간이 2개 미만이거나 0 이하 값이 있음0보다 큰 고장 시간을 2개 이상 넣음
”에이전트 미연결”웹이 API에 닿지 못함API 상태 확인. 그동안은 다운로드로 스크립트를 받아 로컬에서 실행
429, RATE_LIMIT_EXCEEDED분당 요청 제한 초과1분 뒤 다시 실행. 제한 값은 API 서버 참고
503, DB_UNAVAILABLEAPI의 DB 연결 설정이 없거나 연결 풀이 찼음EVMOTOR_DATABASE_URL 설정 확인. 시뮬레이션과 분석 자체는 DB 없이 동작
AI 채팅 Agent 모드가 꺼져 있음API가 도는 곳에 Claude Code CLI가 없거나 API가 연결되지 않음Chat 모드를 씀
Chat 모드가 키를 요구함서버에 Anthropic API 키가 설정되지 않음AI 채팅 설정에 본인 키를 넣음

로그인

증상원인조치
로그인 뒤 승인 대기 중에서 멈춤관리자 승인 전관리자가 사용자 관리에서 승인한 뒤 상태 확인
접근 거절 안내관리자가 거절하거나 차단함관리자에게 확인
API가 401, AUTHENTICATION_FAILED토큰이 만료되었거나 헤더 형식이 틀림다시 로그인. 직접 부를 때는 Authorization: Bearer 토큰 형식 확인

장비 연결(장비가 있는 PC)

증상원인조치
수집 시작이 503EVMOTOR_HARDWARE_SERIAL_PORT가 비어 있거나 UART가 연결되지 않음시리얼 포트 설정과 케이블 확인
could not open port포트 이름이 틀렸거나 다른 프로그램(CCS 터미널 등)이 쓰는 중이거나 권한이 없음포트 이름 확인(Windows COM3 형식), 다른 프로그램 종료, Linux는 dialout 그룹 추가
받은 값이 깨진 글자보드와 PC의 baud가 다름양쪽 모두 115200으로 맞춤
모니터 차트가 멈춤WebSocket 연결이 끊겼거나 동시 연결 10개를 넘음다른 모니터 탭을 닫고 새로 고침. 리버스 프록시가 Upgrade 헤더를 넘기는지 확인
CCS에서 “Error connecting to the target”JTAG 케이블, SDS200i USB 인식, 보드 전원, .ccxml 설정 중 하나차례로 확인
펌웨어를 쓴 뒤 모터가 돌지 않음전원, 모터 커넥터, PWM 출력, safety.c 과전류 기준, 엔코더·홀 센서 신호 중 하나24V 전원부터 차례로 확인
