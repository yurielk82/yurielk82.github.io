KPI 시작하기

KPI에 처음 로그인하고, 화면 구성과 모든 화면에 공통인 조작을 익힙니다.

시작 전에 필요한 것

  • 회사 계정. 재직자 계정은 사원 정보에 맞춰 자동으로 만들어집니다. 계정이 없으면 로그인 화면의 회원가입으로 만듭니다.
  • 관리자가 열어 준 메뉴. 새 계정은 메뉴 없이 시작하고, 관리자가 볼 메뉴를 엽니다.
  • PC나 휴대폰의 웹 브라우저. 휴대폰에서도 같은 주소로 엽니다.

로그인하기

  1. 브라우저에서 kpi.dvsharp.com을 엽니다.
  2. 이메일 또는 사번 칸에 이메일이나 사번을 입력합니다.
  3. 비밀번호를 입력합니다.
  4. 이 기기에서 계속 쓰려면 로그인 상태 유지를 켭니다.
  5. 로그인을 누릅니다.

관리자가 만들어 준 계정이나 임시 비밀번호를 받은 계정은 첫 로그인 때 새 비밀번호로 바꿔야 합니다. 화면 안내에 따라 바꿉니다.

비밀번호를 잊었으면 비밀번호를 잊으셨나요? 를 누르고, 이메일이나 사번을 넣은 뒤 재설정 메일 보내기를 누릅니다. 메일의 링크로 새 비밀번호를 정합니다.

메뉴가 보이지 않을 때

로그인 뒤 아래 화면이 나오면 아직 볼 메뉴가 없는 상태입니다.

  • 계정 준비 화면에서는 들어가기를 누릅니다.
  • 열린 메뉴가 없습니다 화면이 나오면 관리자에게 메뉴를 요청합니다. 권한 요청 / 문의를 눌러 필요한 메뉴와 이유를 적어 보냅니다.
  • 관리자가 메뉴를 열면 다시 확인하기를 누릅니다.

화면 구성

PC 화면은 네 부분으로 나뉩니다.

영역하는 일
상단바왼쪽에 지금 보는 1차 메뉴와 화면 이름, 오른쪽에 검색과 계정 메뉴가 있습니다.
왼쪽 레일1차 메뉴를 고릅니다. 위에서부터 공통, 특화, 바닥 고정 묶음 순서입니다.
메뉴 목록고른 1차 메뉴 안의 화면을 묶음별로 보입니다.
본문고른 화면의 카드·차트·표를 보입니다.

휴대폰에서는 1차 메뉴가 화면 아래 탭으로 바뀝니다. 본문 오른쪽 아래의 둥근 단추는 AI 인사이트 채팅입니다(AI 인사이트 쓰기).

상단바의 계정 메뉴에서 비밀번호 변경, 단축키, 알림 설정, 권한 요청 / 문의(관리자 계정에는 없음), 테마를 엽니다. 용어 뜻이 궁금하면 레일 아래의 용어사전을 엽니다.

기준월 고르기

실적 화면은 대부분 기준월 하나를 기준으로 숫자를 보입니다.

기준월을 바꾸려면 화면 위쪽 기준월 칸에서 볼 달을 고릅니다. 고를 수 있는 달은 화면마다 다르며, 종합 현황은 2026년 1월부터 가장 최근 마감월까지입니다. 화면 주소에 기준월이 들어가므로, 주소를 복사해 보내면 받는 사람도 같은 달을 봅니다.

표 다루기

주문·수금·마스터처럼 행이 많은 표는 같은 도구를 씁니다.

  • 컬럼 머리글의 필터 단추를 눌러 엑셀 자동 필터처럼 값을 골라 거릅니다.
  • 컬럼 설정에서 컬럼을 보이거나 숨기고, 순서를 바꾸고, 왼쪽에 고정합니다. 설정은 계정에 저장되어 다음에도 그대로입니다.
  • 행이 많으면 아래 한 페이지 행 수와 다음 페이지로 넘깁니다.

내려받기와 복사

표가 있는 화면은 위쪽 내보내기 메뉴로 자료를 꺼냅니다.

항목결과
표 복사엑셀에 바로 붙여 넣을 수 있게 복사합니다.
엑셀(XLSX)엑셀 파일을 내려받습니다. 큰 표는 준비 중으로 바뀌었다가 준비되면 바로 내려받습니다.
CSV모든 컬럼을 CSV 파일로 내려받습니다.
PDF, 인쇄화면이 지원하면 PDF로 받거나 인쇄합니다.

알림 받기

마감 확정 같은 소식을 이 기기로 받을 수 있습니다.

  1. 계정 메뉴에서 알림 설정을 엽니다.
  2. 받을 종류를 고르고 이 기기에서 켜기를 누릅니다.
  3. 시험 알림을 눌러 알림이 오는지 확인합니다.
알림 종류언제 오나
판매·수금 마감 확정판매·수금 마감이 KPI에 반영되면 바로 옵니다.
아침 요약새벽 검증이 끝난 뒤 영업일 아침에 한 번 옵니다.
데이터 갱신 지연 (관리자)자동 작업이 재시도까지 실패하면 관리자에게 옵니다.

알림 문구에는 금액·비율을 넣지 않습니다. 잠금 화면에 숫자가 드러나지 않게 하기 위해서입니다.
