KPI 영업 데이터 분석·보고운영자 매뉴얼문제 해결

문제 해결

화면에 나오는 안내 문구나 증상으로 원인과 조치를 찾습니다. 사용자가 할 수 있는 조치를 먼저, 관리자가 할 조치를 뒤에 적었습니다.

로그인·권한

증상원인조치
열린 메뉴가 없습니다아직 볼 메뉴가 열리지 않은 계정입니다.사용자는 권한 요청 / 문의로 요청합니다. 관리자는 사용자 관리의 요청함에서 승인합니다.
계정 준비 화면이 나옴계정 정보가 아직 만들어지지 않았습니다.들어가기를 누릅니다.
계정이 정지되었습니다. 관리자에게 문의해 주세요.정지됐거나 만료일이 지난 계정입니다.관리자가 정지 해제하거나 만료일을 고칩니다.
지금 로그인할 수 없습니다. 잠시 뒤 다시 시도해 주세요.로그인 확인을 지금 마칠 수 없습니다.잠시 뒤 다시 로그인합니다. 계속되면 관리자가 운영 알림을 확인합니다.
비밀번호를 잊음비밀번호를 기억하지 못합니다.로그인 화면의 비밀번호를 잊으셨나요? 로 재설정 메일을 받습니다. 메일이 오지 않으면 관리자가 비밀번호 재설정에서 임시 비밀번호를 발급합니다.
영업사원 계정으로 로그인하면 일보 앱으로 감영업사원 프리셋은 KPI 화면을 열지 않는 현장 전용 계정입니다.KPI 화면이 필요하면 관리자가 프리셋을 바꿉니다.
접근 권한이 없습니다그 화면이 속한 1차 메뉴 권한이 없습니다.같은 화면의 권한 요청 단추나 권한 요청 / 문의로 요청합니다.

숫자·화면

증상원인조치
KPI 본표 발행 대기그 달 실적 발행본이 아직 없습니다.마감·발행이 끝난 뒤 새로고침합니다.
지표 재계산 미완료원본이 바뀐 뒤 지표 다시 계산이 끝나지 않았습니다.자동 재시도 뒤 새로고침합니다. 관리자는 월간 KPI의 BI에서 갱신을 누릅니다.
선택할 수 없는 기준월입니다고를 수 있는 범위 밖의 달입니다.범위 안의 달을 고릅니다. 종합 현황은 2026년 1월부터 최근 마감월까지입니다.
월 보고서에 BI 판매가 반영되면 표가 채워집니다그 달 판매가 아직 반영되지 않았습니다.이전 달을 보거나 반영을 기다립니다.
오늘 판매·수금이 안 보임원천에서 아직 마감되지 않았습니다.마감 현황에서 그 구분의 마감 여부를 봅니다.
카드·표에 자료 없음그 조건의 원천 자료가 없습니다. 0과 다릅니다.기준월과 필터를 확인합니다.
증감 화면에 증감 분석 자료가 바뀌었습니다원본이 발행본을 만든 뒤 바뀌었습니다.증감 다시 조회를 누릅니다.
같은 매출이 화면마다 다름담당자 기준(거래 당시·현재), 실적 정의, 발행본과 현재 원본의 차이입니다.화면의 기준 안내 단추를 열어 기준을 맞춘 뒤 비교합니다. 그래도 다르면 데이터 대조에서 그 달 상태를 봅니다.
새 버전이 배포됐습니다화면을 연 뒤 새 버전이 배포됐습니다.새로고침합니다.

내려받기·업로드

증상원인조치
엑셀(XLSX) 이 준비 중에서 멈춤큰 표의 엑셀 파일을 만드는 중입니다.준비되면 바로 내려받습니다. 오래 밀린 요청은 취소되며, 그때 다시 누르면 바로 만들어 받습니다.
유비스트 업로드에 줄 수가 크게 주는 달 확인이 나옴새 파일의 어떤 달 줄 수가 이전보다 크게 줄었습니다.유비스트에서 받을 때 조건이 바뀌지 않았는지 봅니다. 파일이 맞으면 그래도 반영을 누릅니다.
사업자 휴·폐업 조회가 조회 실행 시간 초과로 끝남국세청 조회가 제한 시간 안에 끝나지 않았습니다.잠시 뒤 다시 조회합니다.

AI 인사이트

증상원인조치
글에 만든 뒤 자료가 바뀜글을 만든 뒤 원본이 갱신됐습니다.다시 만들기를 누릅니다.
글에 안 맞은 N개 뺌근거 숫자와 맞지 않은 문장을 뺐습니다.정상 동작입니다. 남은 문장만 씁니다.
만들기·질문이 되지 않음사용 한도(만들기 10분에 3번, 질문 10분에 10번)에 걸렸습니다.잠시 뒤 다시 합니다.
AI가 전혀 답하지 않음AI 연결 설정이 비었거나 AI 회사 쪽 오류입니다.관리자가 AI 설정에서 회사·키·모델을 확인합니다.

운영(관리자)

증상원인조치
데이터 갱신 지연 (관리자) 알림자동 작업이 재시도까지 실패했습니다.데이터 갱신 현황에서 늦은 자료와 최근 실행을 확인합니다. 원천 쪽 장애면 원천이 돌아온 뒤 다음 실행을 확인합니다.
월간 KPI에 BI 대조 미검증새벽 검증이 그 기준월을 아직 판정하지 않았습니다.다음 날 아침 다시 봅니다. 계속 미검증이면 데이터 갱신 현황에서 새벽 검증의 최근 실행을 봅니다.
공공 데이터 화면이 오래된 값공공 API 수집이 실패했거나 아직 공개되지 않은 달입니다.공공 API 수집 현황에서 마지막 수집을 봅니다. 키 문제면 공공데이터 API 설정에서 연결 테스트를 합니다.
배포가 배포 전 검사에서 멈춤적용하지 않은 DB 마이그레이션이 있거나 RLS 감사가 실패했습니다.백업 뒤 마이그레이션을 적용하고 다시 배포합니다(배포).
배포 뒤 새 버전이 뜨지 않음새 버전의 상태 확인이 실패해 이전 버전이 그대로 있습니다.배포 실패 기록의 단계와 사유를 보고 고친 뒤 다시 배포합니다.
화면이 느림특정 화면의 응답 시간이 늘었습니다.화면 속도에서 메뉴별 응답 시간과 기준선을 봅니다.
