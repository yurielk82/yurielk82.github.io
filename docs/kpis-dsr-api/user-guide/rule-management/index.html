규칙·코드매핑 관리하기

같은 보정을 매번 손으로 하지 않도록 규칙, 코드매핑, 단가오류 학습을 등록합니다. 등록한 내용은 날짜를 열 때 미보고·반송 줄에 자동으로 적용됩니다.

시작 전에 필요한 것

  • 날짜 하나를 연 상태(갑지·을지 고치기). 세 도구 모두 위쪽 도구 메뉴에 있습니다.

자동 적용 순서

날짜를 열면 아래 순서로 미보고·반송 줄을 고칩니다. 접수·포털 제출·결과 미확인 줄은 건드리지 않습니다.

  1. 코드매핑. 저장된 제품명·규격과 같은 줄에 표준코드를 채웁니다.
  2. 마스터 매칭. 표준코드 마스터에서 표준코드를 찾습니다.
  3. 단가오류 자동수정. 켜 둔 단가 코드(DC·DE·DH)마다 단가가 상한가의 정한 비율 안에 드는 줄에 반송사유코드를 채웁니다.
  4. 규격보정. 공급규격을 표준코드 마스터에 맞춥니다.
  5. 규칙. 활성화한 규칙을 우선순위대로 실행합니다.

적용한 내용은 도구 › 수정이력에 규칙 적용, 자동 보정, 자동 매칭으로 남습니다.

규칙 만들기

규칙은 공급구분마다 따로 둡니다.

  1. 사이드바 공급구분에서 규칙을 둘 구분을 고릅니다.
  2. 도구 › 규칙관리를 누릅니다. 제목에 지금 공급구분 이름이 붙은 규칙 관리 창이 열립니다.
  3. 새 규칙 만들기를 누릅니다.
  4. 규칙명(필수), 우선순위, 설명을 넣습니다.
  5. 조건 추가로 조건을 넣습니다. 조건은 모두 맞을 때만 실행합니다.
  6. 액션 추가로 실행할 일을 넣습니다.
  7. 바로 쓰려면 활성화됨 상태인지 확인하고 저장을 누릅니다.
조건 연산자액션
같음, 다름, 포함, 포함하지 않음, 로 시작, 로 끝남값 설정, 값 지우기
초과, 미만, 이상, 이하곱하기, 나누기, 더하기, 빼기
비어있음, 비어있지 않음표준코드 자동채우기, 다른 필드 복사

액션 없이 저장하면 액션없음으로 표시되고 조건 확인용으로만 남습니다.

규칙 카드에서는 켜고 끄기, 상세 보기, 수정, 복사, 삭제를 합니다.

코드매핑 관리하기

표준코드 검색에서 줄에 표준코드를 고르면 그 제품명·규격·포장과 표준코드의 짝이 코드매핑으로 저장됩니다. 다음부터 같은 제품명이 들어오면 자동으로 채웁니다.

  1. 도구 › 코드매핑을 누릅니다. 코드매핑 관리 창이 열립니다.
  2. 검색 칸에 제품명, 표준코드, 규격, 포장형태를 넣어 찾습니다. 줄마다 규격, 포장, 사용 횟수가 보입니다.
  3. 틀린 매핑은 매핑 삭제를 누릅니다. 그 매핑으로 채운 줄의 표준코드도 함께 해제됩니다.

단가오류 학습하기

KPIS가 단가 오류(DC·DE·DH)로 반송한 줄의 단가와 상한가 비율을 학습해, 다음부터 같은 줄에 반송사유코드를 자동으로 채웁니다.

  1. 도구 › 단가오류 학습을 누릅니다.
  2. 오류 연번 입력 칸에 KPIS 오류 엑셀 A열(연번)을 붙여 넣습니다. 쉼표, 줄바꿈, 탭으로 나눠도 됩니다.
  3. 학습을 누릅니다. 줄마다 단가, 상한가, 비율, 코드와 학습 또는 스킵 결과가 보입니다.
  4. 자동채움에서 DC, DE, DH 코드마다 비율을 정하고 미리 본 뒤 적용합니다. 켜 둔 코드는 날짜를 열 때 자동수정에 쓰입니다.
  5. 학습 현황에서 표준코드별 최대비율과 상한가를 보고, 틀린 학습은 지웁니다.

반송사유 칸에 직접 DC·DE·DH를 골라 넣어도 그 표준코드에 대해 학습합니다.

저장 위치

규칙과 수정 이력은 지금 쓰는 브라우저에만 저장됩니다. 다른 PC나 다른 브라우저에서는 보이지 않으므로 규칙은 늘 쓰는 브라우저에서 만듭니다. 수정 이력은 최근 1,000건만 남습니다. 코드매핑과 단가오류 학습·자동채움 설정은 데이터베이스에 저장되어 모든 사용자가 같이 씁니다.

결과 확인

  • 다른 날짜를 열었을 때 같은 보정이 수정이력에 자동으로 남으면 등록이 된 것입니다.
  • 사이드바의 오류 건수가 줄어드는지 봅니다.

잘 안 될 때

  • 규칙이 적용되지 않으면 활성화 상태, 공급구분, 조건이 모두 맞는지 상세 보기로 확인합니다.
  • 잠긴 줄(접수·포털 제출·결과 미확인)에는 어떤 자동 보정도 적용하지 않습니다.
