매일 보고 상태 확인하기

아침마다 전날까지의 공급내역이 KPIS에 제대로 보고됐는지 확인하고, 사람이 볼 날을 찾습니다. 보고 자체는 자동 보고가 하므로 평소에는 이 확인만 하면 됩니다.

시작 전에 필요한 것

  • 승인된 계정
  • 직접 보고하거나 결과를 정리하려면 관리자 계정

확인 순서

  1. 사이드바에서 대시보드를 누릅니다. 공급내역 현황판이 열립니다.
  2. 오른쪽 위에서 월별을 고르고, 달 선택으로 확인할 달을 맞춥니다. 아래 카드는 모두 이 달을 따릅니다.
  3. 맨 위 적기보고율 줄에서 자사 적기보고율과 타사 적기보고율이 목표 95% 이상인지 봅니다. 목표 미달이면 이 쪽 아래 “적기보고율이 목표 아래일 때”를 봅니다.
  4. 할 일(날짜별 공급내역 보고)에서 어제 날짜 카드의 큰 글자를 읽습니다. 보고 완료와 API 접수 확인이면 그날은 끝입니다.
  5. 다른 상태이면 아래 “날짜 상태와 할 일” 표에 따라 처리합니다.
  6. 반송·반송신청 줄이 보이면 반송 처리를 눌러 반송 줄을 봅니다(반송 줄 고쳐 다시 보고하기).
  7. 주문·바코드·KPIS 날짜별 대조에서 다른 날만을 켜고 다른 날이 있는지 봅니다(주문·KPIS 대조 확인하기).
  8. 사이드바 KPIS 보고에서 로그 탭을 열고 확인·오류만을 켭니다. 자동 보고·물류 마감·판매 마감 뒤 검사가 남긴 보류와 오류를 읽습니다.

결과 확인

할 일의 평일 카드가 모두 보고 완료, 보고 대상 없음, 휴일 중 하나이고 로그에 새 오류가 없으면 확인이 끝납니다.

날짜 상태와 할 일

카드의 큰 글자는 보고 상태, 작은 글자는 그 까닭입니다. 위에 있는 상태일수록 먼저 처리합니다.

참고: 엑셀 다운로드와 수기보고 완료 표시는 KPIS 접수를 증명하지 않습니다. 접수 여부는 API 접수 확인이나 업무포털에서 봅니다.

할 일 화면 쓰는 법

  • 주간은 월~금 5일을 한 줄로, 월 달력은 그달 평일을 달력으로 보여 줍니다.
  • 이전·다음 기간 버튼, 날짜 선택, 이번 주로 옮겨 다닙니다. 오늘 날짜는 테두리로 표시합니다.
  • 토·일은 카드로 보이지 않지만 주말 공급 자료도 보고 대상에 들어갑니다.
  • 공휴일과 회사 휴무는 붉은 글자로 표시합니다. 휴일에 실린 공급 자료가 있으면 보고 대상으로 남습니다.
  • 카드 오른쪽 ⋯ 메뉴에는 그날 갑지 건수, 변경 내용 확인, API 결과 다시 확인, 보고 상세 열기, 공급구분별 엑셀 다운로드, 데이터 받아오기, 휴일 관리에서 휴무 변경이 있습니다. 수기보고 완료 표시와 해제는 엑셀을 내려받은 날에만 보이고 관리자만 씁니다.
  • 여러 날을 한꺼번에 보내려면 일괄 보고 검토를 누릅니다(KPIS에 보고하기).

그 밖의 카드

  • 공급 현황: 출고금액·반품금액·순매출(출고 − 반품)을 일·월·연 단위로 봅니다. 그래프, 표, 둘 다 가운데 고릅니다. 자료가 없거나 아직 오지 않은 기간은 0으로 표시하지 않습니다.
  • 주문·바코드·KPIS 날짜별 대조: 날짜·공급구분마다 주문 금액, 바코드 줄·수량·금액, KPIS 건·수량·금액을 놓고 주문=바코드, 바코드=KPIS, KPIS=주문 일치 여부와 왜 다른가를 보여 줍니다. 오늘은 KPIS 집계가 확정 전이라 어제까지만 견줍니다.
  • 참고 › KPIS 정보: **표준코드 마스터 갱신(MA118)**으로 심평원 표준코드를 받아 우리 마스터를 고치고, **입고내역 (MA115)**에서 우리에게 들어온 공급내역을 조회합니다.
  • 연도별 탭은 여러 해의 보고 지표를 비교합니다.

적기보고율이 목표 아래일 때

적기보고율은 기한 안 보고수량을 분기 공급수량으로 나눈 값입니다. 심평원 집계로 계산하며 엑셀 다운로드나 수기 완료 표시로 계산하지 않습니다. 목표 아래로 내려가면 자동으로 로그에 남습니다. 늦은 보고가 생긴 날과 반송 줄을 먼저 확인합니다. 기한(공급월 다음 달 말일)이 지난 줄을 고칠 때는 새 줄로 보내지 않고 반송신청 뒤 업무포털 반송보고로 고칩니다. 새 줄로 보내면 늦은 보고로 잡혀 적기보고율이 더 떨어집니다.

잘 안 될 때

  • 카드가 비어 있거나 날짜 현황 조회 중에서 멈추면 다시 조회를 누릅니다.
  • 적기보고율에 설정 필요가 보이면 관리자가 KPIS 연동 키의 보고 설정(클라이언트 아이디·시크릿, 보고 사업자번호)을 확인합니다.
  • 그 밖은 문제 해결을 봅니다.
