설정과 사용자 관리하기

관리자가 KPIS 연동 키, 자동 보고, 바코드 서버 경로, 사용자 승인, 표준코드 마스터를 관리합니다. 설정은 관리자만 바꿀 수 있고, 다른 사용자에게는 “설정은 관리자만 바꿀 수 있습니다.”가 보입니다.

KPIS 연동 키 넣기

보고에는 클라이언트 아이디·시크릿(JWT 발급용)이, 조회에는 서비스별 조회 키(API KEY)가 필요합니다.

키 받기

  1. KPIS 포털(심평원 업무포털)에 로그인합니다.
  2. 마이페이지 › 내정보 수정 › OPEN API 탭에서 신청합니다.
  3. 승인되면 업무포털 화면에 클라이언트 아이디가 나오고, 시크릿은 메일로 옵니다. 업체당 한 쌍입니다.
  4. 조회 키는 같은 OPEN API 탭에서 서비스마다 받습니다.

보고 설정 저장하기

  1. 사이드바 설정에서 KPIS 연동 키를 누릅니다.
  2. 서버를 고릅니다. 운영은 실제 보고, 개발은 시험용입니다.
  3. 보고 사업자번호에 숫자 10자리를 넣습니다.
  4. 클라이언트 아이디와 클라이언트 시크릿을 넣습니다. 이미 저장돼 있으면 바꿀 때만 넣습니다.
  5. API 보고 시작일을 정합니다. 이 날짜 전은 포털 보고분으로 보고 보내지 않습니다. 비워 두면 API 보고를 할 수 없습니다.
  6. 연결 테스트를 누릅니다. 연결 성공이 보이면 토큰 발급이 된 것입니다.
  7. 저장을 누릅니다. “보고 설정을 저장했습니다”가 보입니다.

저장한 아이디·시크릿은 서버가 암호화해 두고 다시 보여 주지 않습니다. 화면에서 넣은 값이 없으면 서버 환경변수 값을 씁니다. 지금 어느 쪽을 쓰는지는 화면에서 저장한 값 사용 중 또는 서버 환경변수 값 사용 중으로 보입니다.

조회 키 저장하기

  1. 같은 화면의 **조회 키 (API KEY)**에서 서비스마다 승인키를 넣습니다.
  2. 서비스 옆 테스트를 눌러 키를 확인합니다.
  3. 조회 키 저장을 누릅니다.

공급 집계 그래프, 보고 전 이미 접수 검사, 주문·KPIS 대조는 공급내역 집계 조회(MA110) 키를 씁니다. 이 키가 없으면 KPIS 집계를 받지 못해 대조를 할 수 없습니다. 적기보고율(MA116)과 입고내역(MA115)은 조회 키가 아니라 보고용 클라이언트 아이디·시크릿으로 조회합니다.

자동 보고 켜고 끄기

  1. KPIS 연동 키에서 API 보고 시작일이 정해져 있는지 확인합니다.
  2. 자동 보고를 켭니다. 켜면 물류 마감 적재가 끝난 직후와, 마감이 없어도 밤 11시에 싣고 API로 보고합니다.
  3. 저장을 누릅니다.

끄면 꺼짐으로 보이고, 보고는 KPIS에 보고하기대로 사람이 합니다. 보류·실패와 보고한 날의 정정·취소는 KPIS 보고 › 로그에 남습니다. 동작은 자동 보고 흐름에 있습니다.

바코드 서버 경로 정하기

  1. 사이드바 설정에서 데이터소스를 누릅니다. 데이터소스 관리가 열리고 현재 활성 경로가 보입니다.
  2. 직접 연결(서버가 바코드 서버를 직접 읽는 경로) 또는 릴레이 서버(중계 서버 경유) 가운데 하나를 켭니다. 두 경로를 동시에 켤 수는 없습니다.
  3. 저장을 누릅니다.

둘 다 끄면 **비활성 (엑셀 폴백)**이 되고 데이터 가져오기는 엑셀 올리기로 바뀝니다. 운영에서는 직접 연결을 씁니다.

휴일 바꾸기

휴일(공휴일·회사 휴무)의 원본은 KPI.의 휴일 관리입니다. 이 시스템은 읽기만 합니다.

  1. 사이드바 설정에서 휴일 관리를 누릅니다. KPI.의 휴일 관리 화면이 새 탭으로 열립니다.
  2. 그 화면에서 휴일을 바꿉니다.
  3. 대시보드로 돌아와 다시 조회를 누릅니다.

출고정지나 재고실사처럼 공급만 없는 날은 휴일로 넣지 않습니다. 갑지가 없는 날은 공급이 없는 날로 봅니다.

사용자 승인하기

  1. 사이드바 설정에서 사용자관리를 누릅니다. 이 메뉴는 관리자에게만 보입니다.
  2. 승인 대기 목록에서 사용자를 확인하고 승인을 누릅니다.
  3. 권한을 거두려면 승인됨 목록에서 승인 취소를, 계정을 지우려면 삭제를 누릅니다.

관리자 계정에는 관리자 표시가, 지금 로그인한 계정에는 나 표시가 붙습니다.

표준코드 마스터 관리하기

  1. 사이드바 자료에서 마스터 DB를 누릅니다. 마스터 DB 관리가 열립니다.
  2. 위쪽 숫자로 통합, 코드매핑조회, 바코드 마스터 건수를 봅니다.
  3. 검색 칸에 표준코드나 제품명을 넣고 검색을 누릅니다.
  4. 마스터를 바꾸려면 엑셀 업로드를 쓰고, 내려받으려면 엑셀 다운로드를 씁니다. 출처별로 지우는 버튼은 삭제: 옆에 있습니다.
  5. 공공데이터 비교에서 업체명을 넣고 비교를 누르면 공공데이터와 우리 마스터의 차이를 봅니다. 자동 매칭이 놓친 줄은 강제 업데이트로 맞추고, 결과는 엑셀로 내려받습니다.

심평원 표준코드 전체로 마스터를 고치려면 대시보드 › 참고 › KPIS 정보의 **표준코드 마스터 갱신(MA118)**을 씁니다.

결과 확인

  • KPIS 연동 키에서 연결 성공이 보이고, 조회 키마다 테스트가 확인되면 키가 맞습니다. 대시보드 적기보고율에 값이 나오는지도 봅니다.
  • 자동 보고를 켠 다음 날 KPIS 보고 › 로그에 자동 보고 기록이 생기면 동작하는 것입니다.

잘 안 될 때

  • “신규 API 키 승인 대기”가 보이면 심평원 승인을 기다립니다. 승인 전에는 보고·반송신청·적기보고율·입고내역을 쓸 수 없습니다.
  • 연결 실패가 나면 서버(운영·개발)와 사업자번호가 키를 받은 업체와 같은지 확인합니다.
  • 그 밖은 문제 해결을 봅니다.
