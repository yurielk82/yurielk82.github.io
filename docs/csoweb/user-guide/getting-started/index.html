가입하고 로그인하기

참고: CSO 정산 포털의 정산 업무는 2026-09-29에 다른 정산 시스템으로 옮겼습니다. 이 쪽은 운영 당시 화면 기준 기록입니다.

회원사가 포털 계정을 만들고 처음 로그인하기까지의 순서입니다. 대상은 회원사 담당자입니다. 포털은 관리자 승인제라서 가입 신청과 서류 제출 뒤 관리자가 승인해야 로그인할 수 있습니다.

시작 전에 필요한 것

  • 국세청에 계속사업자로 등록된 사업자번호 10자리
  • 정산 안내를 받을 CSO담당자 연락처와 이메일
  • 정산 입금 은행과 계좌번호
  • 서류 네 가지의 파일: 사업자등록증, CSO신고증, 교육이수증, 통장사본. PDF, JPG, PNG 파일이고 한 파일이 10MB 이하여야 합니다.

가입 신청하기

  1. 로그인 화면 아래 회원가입 링크를 누릅니다.
  2. 사업자번호 칸에 숫자 10자리를 입력합니다.
  3. 국세청 확인 결과가 계속사업자로 나오는지 봅니다. 10자리를 다 입력하면 확인이 저절로 시작됩니다.
  4. **업체명 (사업자등록증과 일치)**과 대표자명을 입력합니다.
  5. 주소 검색을 눌러 도로명 주소를 고르고 상세 주소를 입력합니다.
  6. CSO담당자 연락처와 CSO담당자 이메일을 입력합니다. 대표자 연락처와 이메일2는 비워 둬도 됩니다.
  7. **은행명 (정산 입금)**에서 은행을 고르고 계좌번호를 입력합니다.
  8. 비밀번호와 비밀번호 확인을 입력합니다. 영문과 숫자를 섞어 6자 이상으로 만듭니다.
  9. 비밀번호 아래 확인 목록의 6자 이상, 영문 포함, 숫자 포함, 비밀번호 일치가 모두 채워졌는지 봅니다.
  10. 회원가입 신청을 누릅니다.

주의: 사업자번호는 로그인 아이디입니다. 가입한 뒤에는 바꿀 수 없습니다.

서류 제출하기

가입 신청을 누르면 서류 제출 화면으로 넘어갑니다.

  1. 필수 서류 첨부에서 서류 네 가지를 하나씩 올립니다.
  2. 네 가지가 모두 올라갔는지 확인합니다.
  3. 서류 제출 완료를 누릅니다.

서류를 처음 제출하면 관리자에게 가입 신청 알림 메일이 갑니다. 그다음 화면은 로그인 화면으로 돌아갑니다.

승인 뒤 로그인하기

관리자가 승인하면 등록한 이메일로 승인 안내가 옵니다. 그 뒤에 로그인합니다.

  1. 로그인 화면에서 사업자번호와 비밀번호를 입력합니다.
  2. 로그인을 누릅니다.
  3. 홈 화면이 열리면 로그인이 끝난 것입니다.

로그인 상태는 24시간 유지됩니다. 24시간이 지나면 다시 로그인합니다.

처음 로그인할 때 추가로 나오는 화면

계정 상태에 따라 홈으로 가기 전에 다음 화면이 차례로 나올 수 있습니다.

화면나오는 경우할 일
비밀번호 변경 필요관리자가 임시 비밀번호를 준 경우새 비밀번호와 새 비밀번호 확인을 입력하고 비밀번호 변경을 누릅니다. 사업자번호나 그 끝 다섯 자리는 새 비밀번호로 쓸 수 없습니다.
회원 정보 설정업체 정보나 서류가 빠진 경우1. 프로필과 2. 서류를 채우고 저장하고 계속하기를 누릅니다.
서류 제출서류만 빠진 경우빠진 서류를 올리고 서류 제출 완료를 누릅니다.

비밀번호를 잊었을 때

  1. 로그인 화면에서 **비밀번호를 잊으셨나요?**를 누릅니다.
  2. 사업자번호와 가입 시 등록한 이메일을 입력합니다.
  3. 인증코드 발송을 누릅니다.
  4. 메일로 받은 인증코드를 입력하고 인증코드 확인을 누릅니다.
  5. 새 비밀번호와 비밀번호 확인을 입력하고 비밀번호 변경을 누릅니다.
  6. **비밀번호 변경 완료!**가 나오면 지금 로그인하기를 누릅니다.

인증코드는 30분 동안만 쓸 수 있습니다. 시간이 지났으면 인증코드 재발송을 누릅니다.

잘 안 될 때

화면에 보이는 글뜻할 일
”휴업 상태의 사업자는 가입할 수 없습니다.” 또는 “폐업 상태의 사업자는 가입할 수 없습니다.”국세청 기록이 계속사업자가 아닙니다.국세청 사업자 상태를 정리한 뒤 다시 가입합니다.
”국세청에 등록되지 않은 사업자등록번호입니다.”번호가 틀렸거나 국세청에 없습니다.번호를 확인하고 다시 시도를 누릅니다.
”승인 대기 중입니다. 관리자 승인 후 로그인 가능합니다.”관리자가 아직 승인하지 않았습니다.승인 안내 메일을 기다립니다.
”비밀번호가 일치하지 않습니다. (실패 N/5회)“비밀번호가 틀렸습니다.다시 입력합니다. 다섯 번 틀리면 계정이 잠깁니다.
”로그인 5회 실패로 계정이 잠겼습니다.”다섯 번 틀려 계정이 잠겼습니다.등록한 이메일로 온 비밀번호 변경 링크를 열어 새 비밀번호를 정합니다.
”요청이 너무 많습니다. 잠시 후 다시 시도해주세요.”짧은 시간에 너무 많이 시도했습니다.1분쯤 기다린 뒤 다시 합니다.

이메일도 쓸 수 없으면 관리자에게 비밀번호 초기화를 요청합니다. 관리자가 준 임시 비밀번호로 로그인하면 비밀번호 변경 필요 화면이 나옵니다. 다른 문제는 자주 묻는 질문을 봅니다.
