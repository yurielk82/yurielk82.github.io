CSO 정산 조회 (운영 종료)운영자 매뉴얼모니터링

모니터링

참고: CSO 정산 포털의 정산 업무는 2026-09-29에 다른 정산 시스템으로 옮겼습니다. 이 쪽은 운영 당시 화면 기준 기록입니다.

이 쪽은 관리자가 정산 현황, 메일 발송, 시스템 연결 상태를 어디서 확인하는지 정리합니다.

관리자 대시보드

관리자가 로그인하면 대시보드가 먼저 열립니다. 오른쪽 위에 마지막 갱신 시각이 나옵니다.

정산 현황 탭에는 다음이 있습니다.

영역내용
수수료 총액, CSO 업체최근 정산월의 수수료 합계와 업체 수, 전월 대비 증감
접속률그 달 정산서를 열어 본 업체 비율과 아직 안 본(미조회) 업체 수
할 일정산서 업로드 필요, 승인 대기, CSO 미매칭 건수
빠른 이동자주 쓰는 관리 화면 바로가기
월별 정산 추이달마다 정산 흐름

통계 분석 탭에서는 정산월을 고르면 월별 성장률(전월 대비, 전년 동월 대비), TOP 10 CSO 업체 (수수료), TOP 10 제품 (수량), 제품 구성과 제품별 추이 그래프가 나옵니다.

위 화면은 실제 화면 부품에 가상 자료를 넣어 다시 그린 것입니다.

이메일 이력

위쪽 메뉴 이메일의 이메일 이력에서 포털이 보낸 메일을 봅니다. 한 번에 최근 200건까지 나옵니다.

항목값
카드전체, 발송 성공, 발송 실패, 대기중
기간 필터최근 7일, 30일, 90일, 전체 기간
유형회원가입 신청, 승인 완료, 승인 거부, 정산서 업로드, 비밀번호 재설정, 메일머지, 연결 테스트
상태대기중, 발송됨, 실패, 큐 대기
표의 열상태, 발송일시, 수신자, 제목, 유형

실패한 메일은 오류 내용이 한국어로 풀어서 나옵니다.

이메일 설정

관리자 계정 메뉴의 이메일 설정에서 메일 발송 방식을 정합니다.

설정내용
발송 프로바이더Resend API 또는 SMTP (하이웍스 등)
SMTP 접속 정보저장한 프로필을 고르거나 직접 입력합니다. SMTP 호스트, 포트, 계정, 비밀번호, 발신자명, 발신 이메일
일괄 발송 지연 (초)메일머지 메일 사이 최대 간격. 0.5초부터 30초까지 넣을 수 있고, 화면은 6초 이상을 권합니다.
테스트 수신 이메일연결 테스트 메일을 받을 주소
이메일 알림 설정자동 메일 다섯 종류를 하나씩 켜고 끕니다. 회원가입 신청 알림, 가입 승인 알림, 가입 거부 알림, 정산서 업로드 알림, 비밀번호 재설정
  • SMTP를 고르면 시스템 메일까지 모든 메일이 이메일 워커를 거쳐 나갑니다. 이때 연결 테스트도 워커가 돌고 있어야 성공합니다.
  • 알림 설정을 꺼도 메일머지는 막히지 않습니다. 메일머지는 관리자가 직접 보내는 메일이기 때문입니다.

시스템 정보

관리자 계정 메뉴의 시스템 정보는 읽기 전용 화면입니다. 배포 뒤나 문제가 생겼을 때 먼저 봅니다.

카드보여 주는 것
앱 정보앱 이름, 버전, 실행 환경
배포배포 플랫폼, 주소, 브랜치, 커밋
데이터베이스연결 상태
외부 API국세청 사업자 상태 조회 연결 상태. 심평원 병원·약국 API는 “연결됨 (미사용)“으로 나옵니다.
인증JWT 서명 키 설정 여부와 세션 유지 시간. 키 값은 보이지 않습니다.
이메일 서비스지금 쓰는 발송 방식과 발신 주소

서버 기록과 오류 추적

  • 웹 서버, 이메일 워커, OCR 워커는 각각 systemd 서비스라서 기록이 서버 저널에 쌓입니다. 서비스마다 따로 봅니다.
  • Sentry 주소가 설정되어 있으면 브라우저, 서버, 엣지 오류가 Sentry로 갑니다. 성능 추적은 요청의 10%만 표본으로 남기고, 개발 환경에서는 보내지 않습니다. 이메일 워커의 오류도 Sentry로 갑니다.
